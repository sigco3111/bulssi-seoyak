# 불씨의 서약: 소스 묶음

리드어세상 영상 「AI로 만든 게임, 부업이 될까」에서 만든 웹게임의 소스입니다.
코덱스에게 말로 지시해 3일 동안 만들었고, Claude Fable 5.2가 점검하고 고쳤습니다.
이 묶음을 가져다가 여러분의 게임으로 바꾸셔도 됩니다.

## 1. 그냥 해 보기

같이 받은 `bulssi-seoyak.html` 한 파일을 크롬이나 엣지로 열면 바로 실행됩니다.
설치는 필요 없습니다. 저장은 그 브라우저 안에만 남습니다.

## 2. 고쳐서 다시 만들기

Node.js가 필요합니다.

윈도우(PowerShell):

```
winget install OpenJS.NodeJS.LTS
```

설치한 뒤 PowerShell 창을 닫았다가 다시 엽니다.

맥(터미널):

```
brew install node
```

이 폴더에서 아래 두 줄을 실행합니다.

```
npm install
node design/build.mjs
```

`design/dist/ashen-realms-design.html` 한 파일이 새로 만들어집니다. 이 파일을 브라우저로 열면 됩니다.
이 판에는 영상에서 보여 드린 외형 상품 가격표가 그대로 보입니다(결제는 되지 않습니다).

가격표를 뺀 한 파일판(같이 받은 `bulssi-seoyak.html`과 같은 판)은 이렇게 만듭니다.

```
node design/build.mjs --free
```

`design/dist/ashen-realms-free.html`이 만들어집니다.

웹에 올릴 판(그림과 소리를 따로 받는 가벼운 판)은 이렇게 만듭니다.

```
node design/build.mjs --web
```

`design/dist/web/` 폴더가 만들어지고, 이 폴더를 그대로 Vercel 같은 곳에 올리면 됩니다.

## 3. AI에게 맡겨서 내 게임으로 바꾸기

명령어를 직접 치지 않아도 됩니다. 클로드 코드나 코덱스에서 이 폴더를 열고 이렇게 부탁하세요.

```
이 폴더는 three.js로 만든 웹게임 소스야. README_먼저읽기.md를 읽고, 필요한 걸 설치한 다음 빌드해서 실행되는지 확인해 줘.
```

구조부터 파악시키고 싶으면 REA 스킬을 설치합니다(주소: https://github.com/morluto/rea).

```
npx rea-agents setup
```

설치가 끝나면 클로드 코드나 코덱스를 껐다 켜고 이렇게 부탁하세요.

```
이 게임을 분석해서 나만의 게임으로 바꾸자. 먼저 코드가 어떻게 짜여 있는지 파악해서 쉬운 말로 설명해 줘.
```

그다음부터는 「이름을 바꿔 줘」, 「직업을 하나 더 만들어 줘」, 「이 몬스터가 어색해」처럼 말로 고치면 됩니다.

## 4. 폴더 안내

| 폴더 | 내용 |
|---|---|
| `design/game-design.json` | 직업, 기술, 장비, 사냥터, 밸런스 숫자가 전부 여기 있습니다 |
| `design/src/` | 첫 화면과 전체 틀 |
| `combat/` | 전투, 사냥터, 몬스터, 기술 |
| `equipment/` | 장비, 무기 동작, 외형 |
| `presentation/` | 화면 구성, 대화, 상점, 원화, 소리 |
| `assets/` | 3D 모델과 음악 |
| `presentation/art/generated/prompts/` | 직업과 몬스터 원화를 만들 때 쓴 프롬프트 |

## 5. 쓴 것과 조건

- 사람 모델과 동작: Quaternius의 공개 모델(CC0). 주소는 `design/game-design.json`의 `assetCredits`에 있습니다.
- 3D 엔진: three.js(MIT).
- 글자: Hahmlet(SIL Open Font License 1.1). `presentation/licenses/`에 원문이 있습니다.
- 그림(표지, 인물, 몬스터 원화): AI로 생성했습니다.
- 음악: Google Flow Music으로 만든 AI 음악입니다. 다시 배포하거나 돈을 받는 곳에 쓰기 전에 그 서비스의 이용 조건을 직접 확인하세요.
- 이 소스(코드, 이름, 이야기, 그림)는 자유롭게 고쳐 쓰셔도 됩니다. 그대로 다시 올려 파는 것만 하지 말아 주세요.

## 6. 알아 둘 것

- 알파 단계입니다. 버그가 있을 수 있습니다.
- 한 사람이 하는 게임입니다. 온라인, 로그인, 결제 기능은 없습니다.
- 가격표가 붙은 외형 상품은 보여 주기용입니다. 실제 결제는 되지 않습니다.
- 한국에서 게임을 돈 받고 서비스하려면 등급분류를 받아야 합니다. 무료로 공개할 때도 면제에 해당하는지는 게임물관리위원회에 확인하세요.
